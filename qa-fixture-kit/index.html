Test Base USDC payment edge cases without moving money.

A free, deterministic QA fixture kit for developers testing ERC-20 payment handling. Explore 35 invented receipts and logs, run a Python reference evaluator, and exercise common error conditions — no RPC, wallet, keys, tokens, gas or sign-up required.

Test data, not real payment verification. Every transaction, finalized head and RPC response in this kit is synthetic. Do not use its decisions to authorize actual payments, paid downloads or x402 settlement. It has no trusted production RPC, cryptographic authorization or atomic claim store.

What you can test

Native USDC vs bridged USDbC

Reject payments attributed to the wrong ERC-20 token, network or address.

Exact amount & recipient

Model underpayment, overpayment, wrong payer, wrong recipient and decimal mistakes.

Finality & provider disagreement

Exercise pending, failed, unavailable and conflicting synthetic RPC views.

Replay & event log handling

Check duplicate proof claims, wrong log indexes, malformed events and multiple transfers within a transaction.

Run it offline in two commands

Download the release ZIP asset, extract the contents, then execute from the extracted kit directory using Python 3.10+:

python src/check_cases.py
python -m unittest discover -s tests -v

No dependencies required for core tests. The included site/index.html is an offline searchable browser of all 35 cases.
